 QUICKSTART (Easiest — no install needed)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Make sure Python is installed on your PC
   → Download FREE: https://www.python.org/downloads/
   → During install: TICK "Add Python to PATH" ✔

2. Double-click:  "Run App (Double-Click Me).bat"
   → Installs everything automatically (first run only)
   → Opens your browser with the app ready to use

 BUILD A PROPER .EXE (One-time, optional)

If you want a proper double-click EXE launcher:

1. Double-click: build_windows.bat
2. Wait ~2 minutes
3. Find your EXE in: dist\SocialMediaAgent\SocialMediaAgent.exe
4. Share the entire "SocialMediaAgent" folder (not just the EXE)

 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"python is not recognized"
  → Python not installed or not added to PATH
  → Reinstall from python.org and tick "Add to PATH"

"Port 8501 already in use"
  → Another Streamlit app is running
  → Close other browser tabs / restart PC

Browser doesn't open automatically
  → Manually go to: http://localhost:8501
